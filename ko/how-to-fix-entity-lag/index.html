마인크래프트 엔티티 렉 해결 방법

업데이트 2026-10-26 · Minecraft Java 26.2

엔티티 렉은 마인크래프트가 보이는 모든 엔티티를, 멈춰 있는 것까지 매 프레임 다시 만들기 때문에 생깁니다. 무료 Fabric 모드 Entity Keepsake를 설치하면 바뀌지 않은 갑옷 거치대, 홀로그램, NPC, 아이템 액자, 디스플레이 엔티티의 작업을 재사용합니다. 아무것도 숨기지 않습니다.

Modrinth에서 Entity Keepsake 다운로드 CurseForge에서 다운로드

로비, 허브, 스폰 지역에서 FPS가 떨어지는데 다른 곳에서는 괜찮다면 원인은 아마 엔티티입니다. 홀로그램은 투명 갑옷 거치대를 쌓은 것이고, NPC는 완전한 플레이어 모델이며, 꾸민 건축물에는 아이템 액자와 디스플레이가 가득합니다. 모두 움직이든 아니든 매 프레임 CPU 시간을 씁니다.

단계

  1. Minecraft Java 26.2용 Fabric Loader를 설치하고 Fabric API를 mods 폴더에 넣습니다.
  2. Modrinth에서 Entity Keepsake를 받아 .jar를 같은 mods 폴더에 넣습니다.
  3. Fabric 프로필로 마인크래프트를 실행하고 붐비는 곳으로 갑니다.
  4. /entitykeepsake를 입력하면 재사용되는 엔티티 수를 볼 수 있습니다.

설정할 것은 없습니다. SkyBlock 모드팩의 붐비는 테스트 장면에서 차이는 다음과 같았습니다:

평균 FPS1% low FPS
Entity Keepsake 없음52.440.4
Entity Keepsake 사용85.357.2

직접 차이 확인하기

붐비는 곳에 서서 FPS 표시를 켜고 /entitykeepsake off와 /entitykeepsake on으로 바꿔 보세요. 이상해 보이는 것이 있으면 /entitykeepsake verify가 재사용한 모든 결과를 새로 만든 결과와 비교해 차이를 모두 보여 줍니다.

다른 성능 모드와 함께 쓰기

Entity Keepsake는 Sodium, Lithium, ImmediatelyFast, Entity Culling과 함께 작동합니다. Sodium은 블록을 빠르게 하고, 컬링 모드는 보이지 않는 엔티티를 건너뛰며, Entity Keepsake는 보이는 엔티티를 빠르게 합니다.

자주 묻는 질문

왜 엔티티가 블록보다 렉이 심한가요?
블록은 한 번 청크 메시로 만들어진 뒤 재사용됩니다. 엔티티는 매 프레임 다시 만들어지므로 수백 개가 있으면 멈춰 있어도 CPU를 많이 씁니다.
엔티티가 다르게 보이나요?
아니요. 바뀌는 것은 즉시 다시 만들고, 캐시된 모든 엔티티는 최소 1초에 한 번 처음부터 다시 만듭니다.
몹 농장에도 도움이 되나요?
조금만 됩니다. 움직이는 몹은 항상 다시 만들어집니다. 가장 효과가 큰 건 멈춘 엔티티, 즉 갑옷 거치대, 홀로그램, NPC, 아이템 액자, 디스플레이입니다.
