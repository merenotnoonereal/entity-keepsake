Entity Keepsake

갑옷 거치대, 홀로그램, NPC, 아이템 액자, 디스플레이 엔티티 주변에서 FPS가 오릅니다.

마인크래프트는 한 시간 동안 움직이지 않은 엔티티도 매 프레임 다시 만듭니다. Entity Keepsake는 그 작업을 보관해 두고 다시 씁니다.

Modrinth에서 다운로드 CurseForge에서 다운로드 GitHub

Entity Keepsake는 붐비는 곳의 엔티티 렉을 해결하는 100% 클라이언트 전용 Fabric 성능 모드입니다. 수백 개의 홀로그램 거치대와 NPC가 FPS를 끌어내리는 Hypixel SkyBlock 허브를 위해 만들었으며, 멈춰 있는 엔티티가 많은 서버나 월드라면 어디서든 도움이 됩니다. 아무것도 숨기거나 컬링하거나 제거하지 않습니다. 모든 엔티티는 여전히 매 프레임 그려지므로 게임은 완전히 똑같아 보입니다.

붐비는 곳에서 최대 63% 더 높은 FPS

모드 112개짜리 Hypixel SkyBlock 모드팩에서, 홀로그램 거치대와 플레이어 모양 NPC로 가득한 붐비는 장면으로 테스트했습니다 (번갈아 실행한 결과의 중앙값):

평균 FPS1% low FPS
Entity Keepsake 없음52.440.4
Entity Keepsake 사용85.357.2

1% low가 좋아진다는 것은 숫자만 높아지는 게 아니라 끊김이 줄어든다는 뜻입니다. 향상 폭은 PC와 화면에 있는 멈춘 엔티티 수에 따라 다르며, 붐비는 허브에서 가장 크고 빈 월드에서는 작습니다.

갑옷 거치대와 홀로그램이 렉을 일으키는 이유

마인크래프트는 매 프레임 보이는 모든 엔티티를 처음부터 다시 만듭니다. Hypixel 같은 서버는 홀로그램, NPC 이름, 떠 있는 라벨마다 투명 갑옷 거치대를 쌓아 쓰기 때문에 허브 하나에 수백 개가 있을 수 있습니다. 이걸 매 프레임 전부 다시 만들면 렌더 스레드에서 CPU 시간을 많이 쓰고, 바로 거기서 FPS가 사라집니다.

빨라지는 것

  • 갑옷 거치대: 투명, 마커, 작은, 이름 붙은 갑옷 거치대.
  • 홀로그램과 떠 있는 글자: 홀로그램 묶음, NPC 이름표, 떠 있는 라벨.
  • NPC: 플레이어 모양 NPC, 마네킹, 가만히 서 있는 플레이어. 내 플레이어는 절대 건드리지 않습니다.
  • 아이템이 들어 있는 아이템 액자 (지도는 제외).
  • 디스플레이 엔티티: 블록, 아이템, 텍스트 디스플레이. 나를 향해 도는 것도 포함됩니다.

작동 방식

  1. 렌더 상태 캐시: 엔티티가 어떻게 보여야 하는지에 대한 정보를 다시 만들지 않고 재사용합니다.
  2. 이름표 레이아웃 캐시: 이름표와 홀로그램의 글자 배치를 보관합니다.
  3. 버텍스 재생: 멈춘 갑옷 거치대, 머리, 아이템의 완성된 지오메트리를 카메라 움직임만큼 옮겨서 재사용합니다.
  4. 그리기 재생: 멈춘 갑옷 거치대의 그리기 목록을 기록해 재생하고, 렌더러를 다시 실행하지 않습니다.

아무것도 무조건 재사용하지 않습니다. 지오메트리는 일반 생성을 두 번 연속 했을 때 결과가 완전히 같을 때만 재생합니다.

바닐라와 완전히 똑같은 모습

  • 움직이는 것은 모두 다시 만듭니다. 위치, 회전, 머리 방향, 애니메이션, 디스플레이 업데이트를 매 프레임 확인합니다.
  • 움직이거나, 피해를 입거나, 불타거나, 휘두르는 엔티티는 항상 평소대로 그립니다. 조준점 아래의 엔티티도 마찬가지입니다.
  • 발광 엔티티와 하이라이트도 작동합니다. SkyHanni와 Skyblocker의 하이라이트도 그대로 보입니다.
  • 안전장치: 캐시된 모든 엔티티는 최소 1초에 한 번 처음부터 다시 만들어집니다.

Sodium 및 SkyBlock 모드와 함께 작동

Sodium, Lithium, ImmediatelyFast, Entity Culling, More Culling, SkyHanni, Skyblocker, Odin, Entity Model Features, Entity Texture Features, 3D Skin Layers, Not Enough Animations가 들어 있는 SkyBlock 모드팩에서 테스트했습니다. 위의 FPS는 이 모드들을 설치한 상태로 측정했으므로 Entity Keepsake의 효과는 그 위에 더해집니다. 내장 자가 점검으로 재사용한 모든 결과를 새로 만든 결과와 비교했습니다: 8,669,909번 점검, 차이 0.

사용 방법

  1. Minecraft 26.2용 Fabric Loader와 Fabric API를 설치합니다.
  2. Entity Keepsake .jar를 mods 폴더에 넣고 게임을 실행합니다.
  3. 끝입니다. 알아서 작동하며 설정할 것이 없습니다.

/entitykeepsake는 재사용된 엔티티 수를 보여 줍니다. /entitykeepsake off와 /entitykeepsake on으로 끄고 켜서 FPS를 비교할 수 있습니다. /entitykeepsake verify는 재사용한 모든 결과를 새 결과와 비교합니다.

가이드

  • 마인크래프트 엔티티 렉 해결 방법

  • 갑옷 거치대와 홀로그램이 렉을 일으키는 이유 (영어)

자주 묻는 질문

갑옷 거치대와 홀로그램 때문에 생긴 렉은 어떻게 해결하나요?
Entity Keepsake(Fabric, 클라이언트 전용)를 설치하세요. 바뀌지 않은 갑옷 거치대, 홀로그램, NPC, 아이템 액자, 디스플레이 엔티티의 작업을 매 프레임 다시 만드는 대신 재사용합니다.
엔티티를 숨기거나 컬링하나요?
아니요. 모든 엔티티는 여전히 매 프레임 그려집니다. 바뀌지 않은 엔티티의 작업을 다시 하지 않을 뿐입니다.
Hypixel SkyBlock에서 작동하나요?
네, 그걸 위해 만들었고 거기서 테스트했습니다. 엔티티를 더 빨리 그리게 할 뿐이며 게임상 이점은 전혀 없습니다.
Sodium, Entity Culling과 함께 쓸 수 있나요?
네. FPS 향상은 둘 다 설치한 상태로 측정했습니다. 컬링 모드는 보이지 않는 엔티티를 건너뛰고, Entity Keepsake는 보이는 엔티티를 빠르게 하므로 효과가 더해집니다.
다른 서버와 싱글플레이에서도 작동하나요?
네. 갑옷 거치대, 홀로그램, NPC, 아이템 액자, 디스플레이 엔티티가 많은 월드라면 어디든 도움이 됩니다.
서버에 설치해야 하나요?
아니요. Entity Keepsake는 100% 클라이언트 전용입니다. 본인만 설치하면 됩니다.

Fast Static Entity를 쓰고 있었나요?

Entity Keepsake는 Fast Static Entity를 클린룸 방식으로 다시 만든 모드로, 이름 붙은 갑옷 거치대(홀로그램), 플레이어 모양 NPC, 나를 향해 도는 디스플레이 엔티티, 발광 엔티티도 지원합니다. 추가하기 전에 Fast Static Entity를 빼 주세요. 둘 다 같은 것을 캐시합니다.
