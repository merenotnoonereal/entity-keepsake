Entity Keepsake

在盔甲座、全像文字、NPC、物品展示框與展示實體周圍獲得更高 FPS。

Minecraft 每一格畫面都會重建每個實體，即使它一個小時都沒動過。Entity Keepsake 把這些工作留下來重複使用。

Entity Keepsake 是一款完全在客戶端執行的 Fabric 效能模組，用來解決擁擠場所的實體延遲。它為 Hypixel SkyBlock 的大廳打造，那裡數百個全像文字盔甲座和 NPC 會拉低 FPS；在任何有大量靜止實體的伺服器或世界中它都有幫助。不隱藏、不剔除、不移除任何東西：每個實體仍然每格畫面都會繪製，所以遊戲看起來完全一樣。

擁擠區域 FPS 最多提升 63%

在一個含 112 個模組的 Hypixel SkyBlock 模組包中測試，場景擠滿了全像文字盔甲座與玩家外型的 NPC（交替執行的中位數）：

平均 FPS1% low FPS
未安裝 Entity Keepsake52.440.4

更好的 1% low 代表更少的卡頓，不只是數字更高。提升幅度取決於你的電腦與畫面上靜止實體的數量：在擁擠的大廳最大，在空曠的世界很小。

為什麼盔甲座和全像文字會造成延遲

每一格畫面，Minecraft 都會從零重建每個可見實體。像 Hypixel 這樣的伺服器會為每條全像文字、每個 NPC 名稱和每個浮動標籤堆疊隱形盔甲座，所以一個大廳可能有數百個。每格畫面把它們全部重建會佔用算繪執行緒大量 CPU 時間，你的 FPS 就是在這裡流失的。

它加速哪些東西

  • 盔甲座：隱形、標記、小型與有名稱的盔甲座。
  • 全像文字與浮動文字：全像文字堆、NPC 名牌與浮動標籤。
  • NPC：玩家外型的 NPC、人體模型與站著不動的玩家。你自己的玩家永遠不會被處理。
  • 裝有物品的物品展示框（地圖除外）。
  • 展示實體：方塊、物品與文字展示實體，包括會轉向你的那些。

運作方式

  1. 算繪狀態快取：描述實體外觀的資料會被重複使用，而不是重新建立。
  2. 名牌排版快取：名牌與全像文字的文字排版會被保留。
  3. 頂點重播：靜止的盔甲座、頭顱與物品已完成的幾何會被重複使用，並隨鏡頭移動而平移。
  4. 繪製重播：記錄靜止盔甲座的繪製清單並重播，而不是再次執行它的算繪器。

不會盲目重複使用任何東西。只有連續兩次正常建立的結果完全相同，才會重播幾何。

看起來和原版完全一樣

  • 任何會動的東西都會重建。位置、旋轉、頭部轉動、動畫與展示實體的更新每格畫面都會檢查。
  • 正在移動、受傷、著火或揮動的實體一律正常繪製，準星下的實體也一樣。
  • 發光實體與醒目標示正常運作，所以 SkyHanni 和 Skyblocker 的標示依然顯示。
  • 安全網：每個被快取的實體至少每秒從零重建一次。

相容 Sodium 與 SkyBlock 模組

在包含 Sodium、Lithium、ImmediatelyFast、Entity Culling、More Culling、SkyHanni、Skyblocker、Odin、Entity Model Features、Entity Texture Features、3D Skin Layers 與 Not Enough Animations 的 SkyBlock 模組包中測試。上面的 FPS 是在安裝這些模組的情況下測得的，所以 Entity Keepsake 的提升會疊加在它們之上。內建自我檢查把每個重複使用的結果與新建立的結果比對：8,669,909 次檢查，0 處差異。

使用方式

  1. 為 Minecraft 26.2 安裝 Fabric Loader 與 Fabric API。
  2. 把 Entity Keepsake 的 .jar 放進 mods 資料夾，然後啟動遊戲。
  3. 就這樣。它會自動運作，不需要任何設定。

/entitykeepsake 顯示重複使用了多少實體。/entitykeepsake off 與 /entitykeepsake on 可以關閉和開啟它來比較 FPS。/entitykeepsake verify 會把每個重複使用的結果與新結果比對。

常見問題

如何解決盔甲座和全像文字造成的延遲？
安裝 Entity Keepsake（Fabric，客戶端）。它會重複使用沒有變化的盔甲座、全像文字、NPC、物品展示框與展示實體的工作，而不是每格畫面重建。
它會隱藏或剔除實體嗎？
不會。每個實體仍然每格畫面繪製。它只是不再為沒有變化的實體重複工作。
能在 Hypixel SkyBlock 上使用嗎？
可以，它就是為此打造並在那裡測試的。它只是讓遊戲更快繪製實體，不提供任何遊戲優勢。
能和 Sodium、Entity Culling 一起使用嗎？
可以。FPS 提升就是在兩者都安裝的情況下測得的。剔除類模組略過你看不見的實體；Entity Keepsake 加速你看得見的實體，所以效果可以疊加。
在其他伺服器和單人遊戲中能用嗎？
可以。任何有大量盔甲座、全像文字、NPC、物品展示框或展示實體的世界都能受益。
需要裝在伺服器上嗎？
不需要。Entity Keepsake 完全在客戶端執行，只有你需要安裝。

之前用的是 Fast Static Entity？

Entity Keepsake 是以無塵室方式重寫的 Fast Static Entity，還額外支援有名稱的盔甲座（全像文字）、玩家外型的 NPC、會轉向你的展示實體與發光實體。新增前請先移除 Fast Static Entity：兩者快取的是同樣的東西。
