如何解決 Minecraft 實體延遲

更新於 2026-10-26 · Minecraft Java 26.2

實體延遲來自 Minecraft 每格畫面重建每個可見實體，連靜止的也不例外。安裝免費的 Fabric 模組 Entity Keepsake：它會重複使用沒有變化的盔甲座、全像文字、NPC、物品展示框與展示實體的工作。不隱藏任何東西。

在 Modrinth 下載 Entity Keepsake 在 CurseForge 下載

如果你的 FPS 在大廳、主城與重生點下降，在其他地方卻正常，原因很可能是實體。全像文字是一堆隱形盔甲座，NPC 是完整的玩家模型，裝飾過的建築裡滿是物品展示框與展示實體。不論動不動，它們每格畫面都要消耗 CPU 時間。

步驟

  1. 為 Minecraft Java 26.2 安裝 Fabric Loader，並把 Fabric API 放進 mods 資料夾。
  2. 從 Modrinth 下載 Entity Keepsake，把 .jar 放進同一個 mods 資料夾。
  3. 用 Fabric 設定檔啟動 Minecraft，前往擁擠的地方。
  4. 輸入 /entitykeepsake 查看有多少實體被重複使用。

不需要任何設定。在一個 SkyBlock 模組包的擁擠測試場景中，差別如下：

平均 FPS1% low FPS
未安裝 Entity Keepsake52.440.4
安裝 Entity Keepsake85.357.2

自己檢查差別

站在擁擠的地方，開啟 FPS 顯示，用 /entitykeepsake off 與 /entitykeepsake on 切換模組。如果有什麼看起來不對，/entitykeepsake verify 會把每個重複使用的結果與新建立的結果比對，並列出所有差異。

與其他效能模組一起使用

Entity Keepsake 可以與 Sodium、Lithium、ImmediatelyFast 和 Entity Culling 一起使用。Sodium 加速方塊，剔除類模組略過你看不見的實體，而 Entity Keepsake 加速你看得見的實體。

常見問題

為什麼實體比方塊更容易延遲？
方塊只建立一次區塊網格，之後重複使用。實體每格畫面都要重建，所以數百個實體即使靜止也會消耗大量 CPU。
實體看起來會不一樣嗎？
不會。任何變化都會立即重建，而且每個被快取的實體至少每秒從零重建一次。
對生怪塔有幫助嗎？
只有一點。移動中的生物一律會重建。它對靜止實體幫助最大：盔甲座、全像文字、NPC、物品展示框與展示實體。
