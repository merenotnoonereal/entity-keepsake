A Fast Static Entity alternative that covers holograms and NPCs

Updated 2026-10-26 · Minecraft Java 26.2

Entity Keepsake is a clean-room remake of Fast Static Entity: it was written only from a description of how the original behaves, without looking at its code. It does the same kind of caching and also covers named armor stands (holograms), player NPCs, display entities that face you and glowing entities, which is most of what you see on Hypixel SkyBlock.

Fast Static Entity is a popular mod that speeds up still entities like armor stands. On servers like Hypixel, though, the entities that cost the most are holograms and NPCs, and those weren't the ones it focused on. Entity Keepsake was made to cover them.

What Entity Keepsake covers

  • Armor stands, including invisible, marker, small and named ones (hologram lines).
  • Player NPCs, mannequins and players standing still. Your own player is never touched.
  • Item frames with items (maps are left alone).
  • Display entities: block, item and text displays, including billboarded ones that turn to face you.
  • Glowing entities, with outline colours worked out the same way vanilla does, so SkyHanni and Skyblocker highlights still show.

Beyond render states

Besides reusing render states, Entity Keepsake keeps name tag layouts, replays the finished geometry of still armor stands, heads and items, and replays an armor stand's whole list of draws. Geometry is only replayed after two normal builds in a row came out exactly the same.

How to switch

  1. Remove Fast Static Entity from your mods folder. Don't run both: they cache the same thing.
  2. Add Entity Keepsake and Fabric API (Minecraft 26.2, Fabric).
  3. Launch, go somewhere crowded and type /entitykeepsake to see how many entities are reused.

FAQ

Can I use Entity Keepsake and Fast Static Entity together?
No. They cache the same entities, so use one or the other.
Is Entity Keepsake based on Fast Static Entity's code?
No. It's a clean-room remake: it was written only from a description of how the original behaves, without looking at its code.
Does it change how entities look?
No. Anything that changes is rebuilt, and every cached entity is rebuilt from scratch at least once a second. A built-in self-check found 0 differences in 8,669,909 checks.
