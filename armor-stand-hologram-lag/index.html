Why armor stands and holograms cause lag, and how to fix it

Updated 2026-10-26 · Minecraft Java 26.2

Minecraft rebuilds every visible entity from scratch every frame, even armor stands that never move. Servers use stacks of invisible armor stands for holograms, so one area can have hundreds. Entity Keepsake keeps the work for entities that haven't changed and reuses it, so they still show but cost much less.

Why still entities still cost FPS

Blocks are built once into chunk meshes and reused until something changes. Entities aren't: every frame, Minecraft asks each one for its current state, poses its model, lays out its name tag and builds its geometry again. That's fine for a few mobs, but a hologram with five lines is five armor stands, and a server lobby or a decorated build can have hundreds.

What counts as a still entity

  • Armor stands, including invisible, marker and small ones and the stacks used for holograms.
  • Player-shaped NPCs and players standing still (never your own player).
  • Item frames with items in them.
  • Block, item and text display entities, including ones that turn to face you.

How Entity Keepsake fixes it

It checks each entity every frame. If nothing about it changed, it reuses the render state, the name tag layout and, for armor stands, heads and items, even the finished geometry, shifted for camera movement. Anything that changes is rebuilt right away, and every reused entity is rebuilt from scratch at least once a second as a safety net.

Why not just cull them?

Culling mods like Entity Culling skip entities you can't see, which is great behind walls. But holograms and NPCs are usually in plain sight. Entity Keepsake speeds up the ones you can see, so the two stack: the FPS numbers on the home page were measured with Entity Culling installed.

Install

  1. Install Fabric Loader and Fabric API for Minecraft 26.2.
  2. Put Entity Keepsake in your mods folder.
  3. Type /entitykeepsake in game to see how many entities are reused.

FAQ

Do invisible armor stands cause lag?
Yes. An invisible armor stand with a name is still an entity the game processes every frame, and holograms are made of many of them.
Do item frames cause lag?
Many item frames with items do, since each item is rendered every frame. Entity Keepsake reuses that work for frames that haven't changed. Maps are left alone.
Is it client-side?
Yes. Install it on your client only; it works on any server and in singleplayer.
