Entity Keepsake

在盔甲架、全息文字、NPC、物品展示框和展示实体周围获得更高帧数。

Minecraft 每一帧都会重建每个实体，哪怕它一个小时都没动过。Entity Keepsake 把这些工作留下来重复使用。

Entity Keepsake 是一个完全运行在客户端的 Fabric 性能模组，用来解决拥挤场所的实体卡顿。它为 Hypixel SkyBlock 的主城打造，那里成百上千的全息文字盔甲架和 NPC 会拉低帧数；在任何有大量静止实体的服务器或世界中它都有帮助。不隐藏、不剔除、不删除任何东西：每个实体仍然每帧都会绘制，所以游戏看起来完全一样。

拥挤区域帧数最多提升 63%

在一个含 112 个模组的 Hypixel SkyBlock 整合包中测试，场景里挤满了全息文字盔甲架和玩家外形的 NPC（交替运行的中位数）：

更好的 1% low 意味着更少的卡顿，而不只是数字更高。提升幅度取决于你的电脑和屏幕上静止实体的数量：在拥挤的主城里最大，在空旷的世界里很小。

为什么盔甲架和全息文字会造成卡顿

每一帧，Minecraft 都会从零重建每个可见实体。像 Hypixel 这样的服务器会为每条全息文字、每个 NPC 名字和每个浮动标签叠放隐形盔甲架，所以一个主城可能有上百个。每帧把它们全部重建会占用渲染线程大量 CPU 时间，你的帧数就是在这里流失的。

它加速哪些东西

  • 盔甲架：隐形、标记、小型和带名字的盔甲架。
  • 全息文字和浮动文字：全息文字堆、NPC 名牌和浮动标签。
  • NPC：玩家外形的 NPC、人体模型和站着不动的玩家。你自己的玩家永远不会被处理。
  • 装有物品的物品展示框（地图除外）。
  • 展示实体：方块、物品和文本展示实体，包括会转向你的那些。

工作原理

  1. 渲染状态缓存：描述实体外观的数据会被重复使用，而不是重新构建。
  2. 名牌排版缓存：名牌和全息文字的文字排版会被保留。
  3. 顶点重放：静止的盔甲架、头颅和物品已完成的几何体会被重复使用，并随镜头移动而平移。
  4. 绘制重放：记录静止盔甲架的绘制列表并重放，而不是再次运行它的渲染器。

不会盲目复用任何东西。只有连续两次正常构建的结果完全相同，才会重放几何体。

看起来和原版完全一样

  • 任何移动的东西都会重建。位置、旋转、头部转动、动画和展示实体的更新每帧都会检查。
  • 正在移动、受伤、着火或挥动的实体总是正常绘制，准星下的实体也一样。
  • 发光实体和高亮正常工作，所以 SkyHanni 和 Skyblocker 的高亮依然显示。
  • 安全网：每个被缓存的实体至少每秒从零重建一次。

兼容 Sodium 和 SkyBlock 模组

在包含 Sodium、Lithium、ImmediatelyFast、Entity Culling、More Culling、SkyHanni、Skyblocker、Odin、Entity Model Features、Entity Texture Features、3D Skin Layers 和 Not Enough Animations 的 SkyBlock 整合包中测试。上面的帧数是在安装了这些模组的情况下测得的，所以 Entity Keepsake 的提升是叠加在它们之上的。内置自检把每个复用结果与新构建的结果对比：8,669,909 次检查，0 处差异。

使用方法

  1. 为 Minecraft 26.2 安装 Fabric Loader 和 Fabric API。
  2. 把 Entity Keepsake 的 .jar 放进 mods 文件夹，然后启动游戏。
  3. 就这样。它会自动工作，不需要任何设置。

/entitykeepsake 显示复用了多少实体。/entitykeepsake off 和 /entitykeepsake on 可以关闭和开启它来对比帧数。/entitykeepsake verify 会把每个复用结果与新结果对比。

常见问题

如何解决盔甲架和全息文字造成的卡顿？
安装 Entity Keepsake（Fabric，客户端）。它会复用没有变化的盔甲架、全息文字、NPC、物品展示框和展示实体的工作，而不是每帧重建。
它会隐藏或剔除实体吗？
不会。每个实体仍然每帧绘制。它只是不再为没有变化的实体重复工作。
能在 Hypixel SkyBlock 上用吗？
能，它就是为此打造并在那里测试的。它只是让游戏更快地绘制实体，不提供任何游戏优势。
能和 Sodium、Entity Culling 一起用吗？
能。帧数提升就是在两者都安装的情况下测得的。剔除类模组跳过你看不见的实体；Entity Keepsake 加速你看得见的实体，所以效果可以叠加。
在其他服务器和单人游戏中能用吗？
能。任何有大量盔甲架、全息文字、NPC、物品展示框或展示实体的世界都能受益。
需要装在服务器上吗？
不需要。Entity Keepsake 完全运行在客户端，只有你需要安装。

之前用的是 Fast Static Entity？

Entity Keepsake 是以净室方式重写的 Fast Static Entity，还额外支持带名字的盔甲架（全息文字）、玩家外形的 NPC、会转向你的展示实体和发光实体。添加前请先移除 Fast Static Entity：两者缓存的是同样的东西。
