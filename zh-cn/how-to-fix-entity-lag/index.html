如何解决 Minecraft 实体卡顿

更新于 2026-10-26 · Minecraft Java 26.2

实体卡顿来自 Minecraft 每帧重建每个可见实体，连静止的也不例外。安装免费的 Fabric 模组 Entity Keepsake：它会复用没有变化的盔甲架、全息文字、NPC、物品展示框和展示实体的工作。不隐藏任何东西。

在 Modrinth 下载 Entity Keepsake 在 CurseForge 下载

如果你的帧数在大厅、主城和出生点下降，而在其他地方正常，原因很可能是实体。全息文字是一堆隐形盔甲架，NPC 是完整的玩家模型，装饰过的建筑里满是物品展示框和展示实体。不论动不动，它们每帧都要消耗 CPU 时间。

步骤

  1. 为 Minecraft Java 26.2 安装 Fabric Loader，并把 Fabric API 放进 mods 文件夹。
  2. 从 Modrinth 下载 Entity Keepsake，把 .jar 放进同一个 mods 文件夹。
  3. 用 Fabric 配置启动 Minecraft，前往一个拥挤的地方。
  4. 输入 /entitykeepsake 查看有多少实体被复用。

无需任何设置。在一个 SkyBlock 整合包的拥挤测试场景中，差别如下：

平均帧数1% low 帧数
不装 Entity Keepsake52.440.4
安装 Entity Keepsake85.357.2

自己检查差别

站在拥挤的地方，打开帧数显示，用 /entitykeepsake off 和 /entitykeepsake on 切换模组。如果有什么看起来不对，/entitykeepsake verify 会把每个复用结果与新构建的结果对比，并列出所有差异。

与其他性能模组一起使用

Entity Keepsake 可以与 Sodium、Lithium、ImmediatelyFast 和 Entity Culling 一起使用。Sodium 加速方块，剔除类模组跳过你看不见的实体，而 Entity Keepsake 加速你看得见的实体。

常见问题

为什么实体比方块更容易卡？
方块只构建一次区块网格，之后反复使用。实体每帧都要重建，所以成百上千个实体即使静止也会消耗大量 CPU。
实体看起来会不一样吗？
不会。任何变化都会立即重建，而且每个被缓存的实体至少每秒从零重建一次。
对刷怪塔有帮助吗？
只有一点。移动中的生物总是会重建。它对静止实体帮助最大：盔甲架、全息文字、NPC、物品展示框和展示实体。
