Entity Keepsake

防具立て、ホログラム、NPC、額縁、ディスプレイエンティティの周りで FPS が上がります。

Minecraft は、1 時間動いていないエンティティでも毎フレーム作り直します。Entity Keepsake はその処理結果を取っておき、再利用します。

Modrinth でダウンロード CurseForge でダウンロード GitHub

Entity Keepsake は、混雑した場所でのエンティティによるラグを解消する、100% クライアント側の Fabric 用パフォーマンス Mod です。何百ものホログラム用防具立てや NPC が FPS を下げる Hypixel SkyBlock のハブ向けに作られましたが、止まっているエンティティが多いサーバーやワールドならどこでも効果があります。何も隠さず、カリングも削除もしません。すべてのエンティティは毎フレーム描画され続けるので、見た目はまったく同じです。

混雑した場所で最大 63% FPS アップ

112 個の Mod を入れた Hypixel SkyBlock 向け Modpack で、ホログラム用防具立てとプレイヤー型 NPC が密集したシーンで計測 (交互に実行した結果の中央値):

平均 FPS1% low FPS
Entity Keepsake なし52.440.4
Entity Keepsake あり85.357.2

1% low が良くなるということは、数字が上がるだけでなくカクつきが減るということです。効果は PC と画面上の止まっているエンティティの数によって変わり、混雑したハブで最も大きく、何もないワールドでは小さくなります。

防具立てやホログラムがラグの原因になる理由

Minecraft は毎フレーム、見えているすべてのエンティティをゼロから作り直します。Hypixel のようなサーバーでは、ホログラム、NPC の名前、浮いているラベルのひとつひとつに透明な防具立てを積み重ねて使うため、ひとつのハブに何百個もあります。それを毎フレーム全部作り直すと描画スレッドの CPU 時間を大量に使い、そこで FPS が失われます。

高速化するもの

  • 防具立て: 透明、マーカー、小型、名前付きの防具立て。
  • ホログラムと浮遊テキスト: ホログラムの積み重ね、NPC の名札、浮いているラベル。
  • NPC: プレイヤー型 NPC、マネキン、立ち止まっているプレイヤー。自分のプレイヤーには一切触れません。
  • アイテム入りの額縁 (地図は対象外)。
  • ディスプレイエンティティ: ブロック、アイテム、テキストのディスプレイ。こちらを向くものも含みます。

仕組み

  1. レンダーステートのキャッシュ: エンティティの見た目を表すデータを作り直さずに再利用します。
  2. 名札レイアウトのキャッシュ: 名札とホログラムの文字レイアウトを保持します。
  3. 頂点のリプレイ: 止まっている防具立て、頭、アイテムの完成したジオメトリを、カメラの動きに合わせてずらして再利用します。
  4. 描画のリプレイ: 止まっている防具立ての描画リストを記録して再生し、レンダラーを再実行しません。

何も無条件には再利用しません。ジオメトリは、通常の生成を 2 回続けてまったく同じ結果になったときだけ再生します。

見た目はバニラとまったく同じ

  • 動くものはすべて作り直します。位置、回転、頭の向き、アニメーション、ディスプレイの更新を毎フレーム確認します。
  • 移動中、ダメージを受けている、燃えている、腕を振っているエンティティは常に通常どおり描画します。照準の先にあるエンティティも同様です。
  • 発光エンティティやハイライトも動作します。SkyHanni や Skyblocker のハイライトもそのまま表示されます。
  • 安全策: キャッシュされたエンティティは、少なくとも 1 秒に 1 回ゼロから作り直されます。

Sodium や SkyBlock 用 Mod と一緒に動作

Sodium、Lithium、ImmediatelyFast、Entity Culling、More Culling、SkyHanni、Skyblocker、Odin、Entity Model Features、Entity Texture Features、3D Skin Layers、Not Enough Animations を含む SkyBlock 向け Modpack でテスト済みです。上の FPS はこれらの Mod を入れた状態で計測したもので、Entity Keepsake はその上に上乗せされます。内蔵のセルフチェックで、再利用した結果すべてを新しく作った結果と比較しました: 8,669,909 回のチェックで差異 0。

使い方

  1. Minecraft 26.2 用の Fabric Loader と Fabric API を入れます。
  2. Entity Keepsake の .jar を mods フォルダに入れて起動します。
  3. これで完了です。自動で動作し、設定は不要です。

/entitykeepsake で再利用されたエンティティの数を表示します。/entitykeepsake off と /entitykeepsake on でオフとオンを切り替えて FPS を比べられます。/entitykeepsake verify は再利用した結果を新しい結果と比較します。

よくある質問

防具立てやホログラムによるラグはどう直せますか?
Entity Keepsake (Fabric、クライアント側) を入れてください。変化していない防具立て、ホログラム、NPC、額縁、ディスプレイエンティティの処理結果を、毎フレーム作り直す代わりに再利用します。
エンティティを隠したりカリングしたりしますか?
いいえ。すべてのエンティティは毎フレーム描画され続けます。変化していないエンティティの処理をやり直さないだけです。
Hypixel SkyBlock で使えますか?
はい、そのために作られ、実際にそこでテストしています。エンティティの描画を速くするだけで、ゲーム上の有利は一切ありません。
Sodium や Entity Culling と一緒に使えますか?
はい。FPS の向上は両方を入れた状態で計測しています。カリング系 Mod は見えないエンティティを省き、Entity Keepsake は見えているエンティティを速くするので、効果は重なります。
ほかのサーバーやシングルプレイでも使えますか?
はい。防具立て、ホログラム、NPC、額縁、ディスプレイエンティティが多いワールドならどこでも効果があります。
サーバーに入れる必要はありますか?
いいえ。Entity Keepsake は 100% クライアント側で動作します。自分だけが入れれば大丈夫です。

Fast Static Entity から乗り換えますか?

Entity Keepsake は Fast Static Entity をクリーンルーム方式で作り直した Mod で、名前付き防具立て (ホログラム)、プレイヤー型 NPC、こちらを向くディスプレイエンティティ、発光エンティティにも対応しています。追加する前に Fast Static Entity を外してください。どちらも同じものをキャッシュします。
