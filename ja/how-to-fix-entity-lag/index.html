Minecraft のエンティティラグを解消する方法

更新日 2026-10-26 · Minecraft Java 26.2

エンティティラグは、Minecraft が見えているすべてのエンティティを、止まっているものまで毎フレーム作り直すことで起きます。無料の Fabric Mod Entity Keepsake を入れれば、変化していない防具立て、ホログラム、NPC、額縁、ディスプレイエンティティの処理結果が再利用されます。何も隠しません。

Entity Keepsake を Modrinth でダウンロード CurseForge でダウンロード

ロビー、ハブ、スポーン地点で FPS が落ちるのに、ほかの場所では問題ない場合、原因はおそらくエンティティです。ホログラムは透明な防具立ての積み重ね、NPC はプレイヤーと同じ完全なモデル、飾り付けた建物は額縁やディスプレイだらけです。どれも動いているかどうかに関係なく、毎フレーム CPU 時間を使います。

手順

  1. Minecraft Java 26.2 用の Fabric Loader を入れ、Fabric API を mods フォルダに入れます。
  2. Modrinth から Entity Keepsake をダウンロードし、.jar を同じ mods フォルダに入れます。
  3. Fabric のプロファイルで Minecraft を起動し、混雑した場所に行きます。
  4. /entitykeepsake と入力すると、再利用されているエンティティの数がわかります。

設定は不要です。SkyBlock 向け Modpack の混雑したテストシーンでは、次のような差が出ました:

平均 FPS1% low FPS
Entity Keepsake なし52.440.4
Entity Keepsake あり85.357.2

自分で差を確かめる

混雑した場所に立って FPS 表示をオンにし、/entitykeepsake off と /entitykeepsake on で切り替えてみてください。おかしく見えるものがあれば、/entitykeepsake verify が再利用した結果を新しく作った結果と比較し、差異をすべて表示します。

ほかのパフォーマンス Mod と一緒に使う

Entity Keepsake は Sodium、Lithium、ImmediatelyFast、Entity Culling と一緒に動作します。Sodium はブロックを速くし、カリング系 Mod は見えないエンティティを省き、Entity Keepsake は見えているエンティティを速くします。

よくある質問

なぜエンティティはブロックよりラグが出やすいのですか?
ブロックは一度チャンクのメッシュとして作られ、使い回されます。エンティティは毎フレーム作り直されるため、何百個もあると止まっていても CPU を大量に使います。
エンティティの見た目は変わりますか?
いいえ。変化したものはすぐに作り直され、キャッシュされたエンティティも少なくとも 1 秒に 1 回ゼロから作り直されます。
モブトラップにも効果がありますか?
少しだけです。動いているモブは常に作り直されます。最も効果が出るのは止まっているエンティティ、つまり防具立て、ホログラム、NPC、額縁、ディスプレイです。
