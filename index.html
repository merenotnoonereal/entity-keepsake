Entity Keepsake

More FPS around armor stands, holograms, NPCs, item frames and display entities.

Minecraft rebuilds every entity every frame, even ones that haven't moved in an hour. Entity Keepsake keeps that work and reuses it.

Entity Keepsake is a 100% client-side Fabric performance mod that fixes entity lag in crowded places. It was built for the Hypixel SkyBlock hub, where hundreds of hologram stands and NPCs pull your FPS down, and it helps on any server or world with lots of still entities. Nothing is hidden, culled or removed: every entity is still drawn every frame, so the game looks exactly the same.

Why armor stands and holograms cause lag

Every frame, Minecraft rebuilds every visible entity from scratch. Servers like Hypixel use stacks of invisible armor stands for every hologram, NPC name and floating label, so one hub can have hundreds of them. Rebuilding all of them every frame takes a lot of CPU time on the render thread, and that's where your FPS goes.

What it speeds up

  • Armor stands: invisible, marker, small and named armor stands.
  • Holograms and floating text: hologram stacks, NPC name tags and floating labels.
  • NPCs: player-shaped NPCs, mannequins and players standing still. Your own player is never touched.
  • Item frames with items in them (maps are left alone).
  • Display entities: block, item and text displays, including ones that turn to face you.

How it works

  1. Render state caching: the description of how an entity should look is reused instead of rebuilt.
  2. Name tag layout caching: the text layout of name tags and holograms is kept.
  3. Vertex replay: the finished geometry of still armor stands, heads and items is reused, shifted for camera movement.
  4. Draw replay: a still armor stand's list of draws is recorded and replayed instead of running its renderer again.

Nothing is reused on trust. Geometry is only replayed after two normal builds in a row came out exactly the same.

Looks exactly like vanilla

  • Anything that moves is rebuilt. Position, rotation, head turns, animations and display updates are checked every frame.
  • Moving, hurt, burning or swinging entities are always drawn normally, and so is the entity under your crosshair.
  • Glowing entities and highlights work, so SkyHanni and Skyblocker highlights still show.
  • Safety net: every cached entity is rebuilt from scratch at least once a second.

How to use

  1. Install Fabric Loader and Fabric API for Minecraft 26.2.
  2. Put the Entity Keepsake .jar in your mods folder and launch.
  3. That's it. It works on its own, with nothing to set up.

/entitykeepsake shows how many entities were reused. /entitykeepsake off and /entitykeepsake on turn it off and on to compare FPS. /entitykeepsake verify checks every reused result against a fresh one.

FAQ

How do I fix lag from armor stands and holograms?
Install Entity Keepsake (Fabric, client-side). It reuses the work for armor stands, holograms, NPCs, item frames and display entities that haven't changed, instead of rebuilding them every frame.
Does it hide or cull entities?
No. Every entity is still drawn every frame. It only skips redoing work for entities that haven't changed.
Does it work on Hypixel SkyBlock?
Yes, it was built for it and tested there. It only makes your game draw entities faster and gives no gameplay advantage.
Does it work with Sodium and Entity Culling?
Yes. The FPS gains were measured with both installed. Culling mods skip entities you can't see; Entity Keepsake speeds up the ones you can, so they stack.
Does it work on other servers and in singleplayer?
Yes. Any world with lots of armor stands, holograms, NPCs, item frames or display entities benefits.
Do I need to install it on the server?
No. Entity Keepsake is 100% client-side. Only you need it installed.
